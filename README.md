# AJP VNC — releases

Hier staan de uitvoerbare bestanden van **AJP VNC**, de VNC-viewer van
Automatiseer Jouw Proces voor het overnemen van een Mac via Tailscale.

De app controleert bij het opstarten zelf of hier een nieuwere versie staat en
biedt die aan in het verbindingsvenster. De broncode staat niet in deze
repository.
